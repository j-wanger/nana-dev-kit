## Decision

Three serialized stages, instrument-first, capture-anchored. **Stage A (T1):** make the eval harness hermetic BEFORE anything else — run_hook exports CLAUDE_PROJECT_DIR="$WORK_DIR"; live-state tripwire; seeded-leak self-check (reverted copy must turn the leak test RED — controls-first per [[qa-verification-sweep]]); unset-variant covers the `:-.` fallback; then the post-instrument 52-scenario baseline. **Stage B (T2-T3):** capture a REAL PostToolUse event with provenance BEFORE any fix; three pre-declared evidence-forced branches per hook: remap (signal exists, fix field paths) / redesign (no signal — post-commit verifies via actual git state with failed-commit rigor, detect-loop keys on tool_response.stderr/error markers) / upstream (file platform defect + disable-at-boundary at the checkpoint, pinned-repro criteria N/A-upstream). Fixes: canonical jq parse (detect-loop off raw grep — jq is the kit norm per the health-probe decision; stale "pure bash <50ms" header updated), legacy top-level .exit_code fallback retained (Phase-82 precedent; keeps the 52 eval denominator stable), marker resolution cd-project-dir → project-local .claude/enforce → $HOME/.claude/enforce over the 4-matrix, HEU-002 fail-loud log on signal-absence, parser-edge fixtures, artifact-CONTENT assertions. **Stage C (T4a/T4b):** coverage matrix over all kit-marker-discovered roots (registration presence + copy-currency md5), basename-normalized jq extraction (live registrations are mixed-form), sandbox-rehearsed remediate-then-deregister package with timestamped backup + tested restore, HARD maintainer checkpoint BEFORE any live settings edit, fresh-session post-surgery verification as a one-command check. T5: run-exit-criteria.sh aggregator (10 spec criteria, explicit N/A-upstream pass rule for 3-5), supersession notes for the Phase-82/83 firing zeros measured on the leaky instrument (never rewrite history), README/_ARCHITECTURE rows, MANIFEST regen, drift 0.

Gate outcomes (assumption positions): **A1 accept** (capture-first, three branches); **A2 don't-know → evidence-revised → still don't-know → DEFERRED** (ledger revisit-status open; no live settings execution rides on this gate; the T4a hard checkpoint is the decision point with the completed matrix; maintainer pre-signaled remediate-then-deregister as default); **A3 accept** (WORK_DIR semantics + unset hedge); **A4 dissolved to verified fact** (all four Phase-82 repros confirmed reproducing at HEAD at gate time); **A5 accept** (unchanged 52 denominator, explained-diff discipline, mass unexplained flips = hard stop). all_accept: false; ledger block appended + validated (exit 0).

Alternatives rejected: (a) fix hooks before harness — the instrument would mutate the subject (hooks cd into the live repo during verification); (b) keep detect-loop's pure-grep parser — truncates at embedded quotes; jq is the kit norm; (c) hand-written fixtures matching an assumed event shape — fixture circularity (both hooks' existing tests pass TODAY while dormant against real events); (d) deregister all 11 ghosts without a coverage matrix — would be the 4th cascade-failure instance (gate evidence: ghosts load-bearing for 8 hooks in 3 roots); (e) execute surgery on direction-gate authority alone — rejected by the A2 deferred don't-know.

## Consequences

The eval baseline and all hook-fix verification run on a hermetic instrument — Phase-82/83 firing-rate zeros measured pre-fix get supersession notes, not rewrites. The 52-scenario denominator is preserved via the legacy fallback; any flip must be explained in eval/hook-hygiene/eval-diff.md or the phase hard-stops. Ghost deregistration is checkpoint-gated: an A2 defer leaves ghosts retained-and-documented (registration-exceptions.md) pending the ledger revisit, never silently disarmed consuming projects. If the upstream branch fires for a hook, no code fix ships for it — a platform defect filing + disable-at-boundary option replaces it, and criteria 3-5 pass as N/A-upstream. Every matrix/extraction script must carry a positive control before its output counts (the zsh word-splitting false-0/11 hazard, self-caught at gate time).
