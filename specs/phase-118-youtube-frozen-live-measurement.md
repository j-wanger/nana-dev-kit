# Spec: Phase 118 — YouTube grounded-acquisition frozen live measurement

## Objective
Run the full pre-registered, frozen live feasibility measurement of the Ph116/117 YouTube grounded-acquisition apparatus on a real quarantined corpus (search-query frame), as a feasibility **GO/NO-GO** (n≈12, directional — NOT a population rate estimate): the grounding/drop rate of a **rail-blind** real Sonnet-4.6 extractor, the A1 ASR-misread rate (audio ground truth + a mandatory external clean-context inversion cross-check run OUTSIDE the kit), the A2 uncaptioned dead-letter rate (directional flag, not a mechanical trip), and real per-video + per-batch cost. Anti-retrofit is the entire justification: pre-register ALL parameters + a tamper-evident anchor (git ancestry + SHA-256 of the fetched ids + a keystone `ground()` re-derivation) + a mechanical PASS/FAIL truth table + a minimum-success floor BEFORE any fetch. In the same run, apply a **controlled per-concept bare-model recovery screen** (can a clean model state this claim without the video?) — a SEPARATE quality signal, admissible only scoped-to-post-cutoff content and kept OUT of the feasibility verdict — so a feasibility PASS on a commodity corpus is caught, not assumed. Feasibility gates the downstream value/headroom screen (Ph119, NOT this phase).

## Context
Phase 116 built the acquire→chunk→extract→ground+consolidate core as gitignored apparatus under `companion/research/youtube/`; the grounding rail (`ground/normalize/consolidate/schema.py`) mechanically verifies every extracted `source_quote` is present in its transcript chunk (anti-fabrication). Phase 117 smoke-ran it manual-drive on ONE real quarantined video (`04EL2_Llenc`): 95% grounding (21/22), 0 fabrication, ~$0.02–0.05/video. Ph117 **refuted** the dominant risk this whole line existed to derisk — modern auto-captions are punctuated, so strict-normalization over-drop did not materialize (`present-modulo-punctuation` empty) — and **re-oriented** the A1 concern to ASR word-errors that ground faithfully (the caption mishears "pie" for Pi), which is why the A1 rubric must use audio, not caption text, as ground truth. Ph117 used the free **rail-aware** Claude-as-extractor path (no API key), so the 95% may be inflated; the representative path is a rail-BLIND API extractor, first measured here.

Strategic frame: this project has a 7-deep amplifier-null history — harness headroom does NOT live in re-presenting what a strong bare model already recovers (Ph59/70/71/77/78/80/105). Ph58/59 already CUT active research-injection as net-zero-or-harmful on well-documented topics, with the explicit caveat that it was **never tested on post-cutoff/proprietary content** — the one surviving untested avenue, and exactly what fresh AI-agent-tooling videos are. So the maintainer (Step-13 fork) upgraded the option-B novelty signal from a bare tag to a controlled bare-model recovery screen — the controlled form the project's own method always used. Two agent-internal adversarial reviews forced the anti-retrofit and ToS fixes folded below (C1–C5, M1–M6) BEFORE the freeze.

## Approach
A frozen, pre-registered feasibility measurement with anti-retrofit discipline (Ph87 three-tier authority / Ph97 `.frozen` lineage), plus a pre-registered controlled bare-model recovery screen.

1. **Pre-registration instrument (frozen, committed + pushed BEFORE any fetch).** Tracked `.dev-wiki/phase-118/pre-registration.md`: the deterministic selection function (templated queries over a pinned tool list + fixed sort/locale/date-window + dedupe + a predicate bounding duration/language that CANNOT drop no-caption/blocked videos + `N=12`), all cost stops, the A1 audio-grounded two-step rubric + external-inversion two-key VOID protocol, the A2 directional dead-letter classification + soft-block re-probe + named upward-bias, the novelty per-concept bare-model recovery protocol (pinned judge model/cutoff/prompt), the mechanical PASS/FAIL truth table (boundary stated: mechanical only over {grounding-rate, cost, A2-count, deterministic instrument-controls}; A1 + novelty are judgment layers), the min-success floor (<4 above-floor successes OR <20 pooled grounded concepts → INCONCLUSIVE, not PASS), plus a SHA-256 `rail.sha256` seal of the 4 rail files AND a `prereg.sha256` self-seal (so the prereg cannot be silently amended during T2–T8 to match discovered code).
2. **Two-stage tamper-evident anchor.** PREREG commit (params + seals, pushed to the remote before any search → externally-witnessed ordering) ⟶ CORPUS-FREEZE commit (SHA-256 of the SELECTED id list, captured after the search but BEFORE any fetch/extraction — locks the exact ids since search results drift) ⟶ RESULTS commit. At verify time: `git merge-base --is-ancestor` proves PREREG⟶CORPUS-FREEZE⟶RESULTS and that the ancestry references the specific T1 prereg commit; the frozen id-set EQUALS the telemetry id-set (every frozen id carries an outcome incl. `not-run`/blocked — not a subset); the `rail.sha256` + `prereg.sha256` seals still match; and the **keystone**: re-run the frozen `ground()` on the gitignored `run118/` sidecar whose committed hash matches, reproducing the committed aggregate drop-set / zero-fabrication. Any mismatch = VOID.
3. **Batch runner (`harness118.py`).** A rail-BLIND API-path Sonnet-4.6 extractor (real tokens; its prompt carries NO grounding/verbatim hint — a pinned forbidden-token list makes the absence deterministic), a $10/batch cumulative cap, a telemetry row written for EVERY frozen id (incl. circuit-halted → `not-run`), and a non-optional-stopping resume (fetch only the remaining FIXED frozen ids after cooldown — never "keep fetching until 4 successes"). Retains the Ph117 pacing / circuit-breaker / probe-abort tripwire. The `run118/` telemetry output field-set is pinned as a shared fixture the scorers + verdict import.
4. **Controls-first instrument gates (deterministic, mktemp scratch, HEU-012/Ph82 — each catches a SEEDED defect before it can vouch for a clean verdict; clean-on-seed = instrument-dead = VOID):** a SPLICE (two real adjacent sentences fused) → `ground()` must drop it via `_diag_norm_sentence_safe`; an audio-vs-caption misread (caption X / audio Y / claim asserts X) → the A1 rubric must flag; a no-caption vs 200-empty soft-block → the classifier must separate.
5. **Judgment-layer scorers.** A1 audio-grounded (audio, not caption, as ground truth), ASR-error tally, external clean-context inversion cross-check that must CONCUR before a VOID (two-key), and a logged audit trail of EVERY A1 judgment. A2 directional dead-letter with the soft-block re-probe. Run OUTSIDE the kit where clean-context is required (Ph80 leak).
6. **Novelty bare-model recovery control.** Per grounded concept, a clean-context "can a clean model state this claim WITHOUT the video?" screen, OUTSIDE the kit, with pinned judge model/cutoff/prompt — the controlled form of Ph58/59/78. A separate quality signal, admissible only scoped-to-post-cutoff, explicitly kept OUT of the feasibility PASS/FAIL.
7. **ToS containment.** Verbatim text ONLY under gitignored `run118/`; `.dev-wiki/phase-118/` carries aggregates + hashes only; the gate is `git grep source_quote` (all tracked files, whole repo) + `git check-ignore run118`.
8. **The run (manual-drive) + mechanical verdict.** After the PREREG-commit checkpoint (the maintainer eyeballs the concrete queries + predicate before any fetch), run the search → corpus-freeze → fetch/extract/ground over the frozen N (STOP-and-report after the FIRST video), the A1 external inversion + novelty recovery OUTSIDE the kit, then `results.md` (aggregates + hashes only) with the mechanical verdict + the A1/A2/novelty judgment layers, verified by the anchor + containment gate.

## Constraints (CRITICAL)
- **Rail byte-freeze (load-bearing).** The 4 rail files are byte-unchanged, asserted by `rail.sha256` (NOT the vacuous git-diff on a gitignored tree). A rail change, if ever indicated, is a named later task with its own freeze.
- **Prereg byte-freeze (anti-retrofit, load-bearing).** After the PREREG commit, `pre-registration.md` is sealed (`prereg.sha256`) and NOT amended during implementation; any gap discovered T2–T8 is a VOID/abort condition, never a silent edit to match code.
- **Anti-retrofit anchor (load-bearing).** Git ancestry (PREREG⟶CORPUS-FREEZE⟶RESULTS, referencing the specific prereg commit) + frozen-id-set == telemetry-id-set (every id accounted) + the keystone `ground()` re-derivation on the gitignored sidecar whose committed hash matches. The seal is drift-detecting; the re-derivation is the forge-resistant provenance check.
- **ToS containment (load-bearing).** No TRACKED file carries a verbatim `source_quote` — `git grep source_quote` (whole repo) + `git check-ignore run118` gate before any commit; verbatim only under gitignored `run118/`.
- **Feasibility frame.** n≈12 is a GO/NO-GO, not a rate estimate; A2/whisper is a directional flag with its CI, never a mechanical trip; the resume is non-optional-stopping (fixed frozen N).
- **Novelty out of the verdict.** The recovery signal is a separate judgment layer, admissible only scoped-to-post-cutoff, never part of the mechanical PASS/FAIL — it cannot retrofit the feasibility verdict, nor be quoted whole at the Ph119 value go/no-go.
- **No-peek residual (named validity limit).** No pre-registration can fully mechanize that the queries were authored before peeking at results; minimized by low-discretion templated queries + a can't-drop-failures predicate + an externally-timestamped prereg + the maintainer checkpoint. Recorded, alongside search-query-vs-RSS, as an accepted limit.
- **Quarantine.** The Ph117 smoke video `04EL2_Llenc` MUST NOT enter the frozen corpus (seeing its output would break the freeze).
- **Cost cliff + kill-switches.** $2/video mid-loop + $10/batch cumulative + a 60-call per-video pre-flight ceiling; `--confirm` banned in the measured run. A budget-abort is a recorded finding, never a silent exclusion.
- **Manual-drive.** Live network/API on the maintainer's residential IP (YouTube blocks cloud IPs); deterministic tests use fixtures + a mocked client (no network in the test path).
