Distilled for THIS phase. Detail in [[assumption-surfacer-completeness-screen]] + the phase article.

- **The screen's question is harness-vs-baseline, not recall-of-a-list.** Does the scope+framing surfacer
  BEAT a blind (outcome-unaware) baseline at recovering assumptions the project's history later PROVED
  load-bearing? Ground truth must be OUTCOME-DETERMINED + mechanically extracted (confidence revisions /
  supersessions / blocked tasks / later-phase contradictions), NEVER author-selected — author-selected is
  the review's CRITICAL circularity (a corpus only holds assumptions someone already noticed, so it is
  blind exactly where Jake's A2 reject lives).

- **T1 is a hard GATE.** If non-circular ground truth can't be constructed for ~3 past phases →
  `^PROGRAM-VERDICT: INSTRUMENT-DEAD`, STOP (skip T2–T6). That IS "solve set-completeness before building
  anything," done cheapest-first. INSTRUMENT-DEAD is a valid terminal outcome, not a failure.

- **`surfacer ≈ baseline` ⇒ TERMINATE (5th amplifier null), pre-registered up front.** The framing pass
  ("clean-context reconstruct is-this-worth-solving") is the same bet Ph70/77/78 already nulled (bare
  model recovers what the harness re-presents). State why it would escape that, or accept the null.

- **Three review MAJORs the design must honor:** (1) burial relocates to the COST-SORT (the agent
  under-rates the cost of the item it wants to bury) — so cost-sort is an EXPLICIT logged judgment + a
  cost-sort-ADVERSARIAL control (load-bearing assumption on a deliberately under-rated-cost item) is
  mandatory; (2) a `require`-ERE measures VOCABULARY not recovery for paraphrase-heavy assumptions — use
  ENTITY-presence scoring; (3) n=5/≥4 is cargo-culted — DERIVE the bar from the surfacer's own variance.

- **Two-track verdict, not co-primary-under-one.** Scope track = completeness-property + recovery (the
  easy, scope-local class). Framing track = recovery-only, explicitly WEAKER (the hard class Jake actually
  rejected on; it has NO completeness guarantee). Don't let scope success mask framing failure.
