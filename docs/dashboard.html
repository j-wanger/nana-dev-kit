Options

A — Natural worker, gate ladder, three-way taxonomyRecommendedChosen
Real worker iterates naturally (not told to game) against each gate rung; measure the silent-wrong rate as the gate weakens. Three-way classification of held-out-fail runs {silent-wrong | special-cased | honest-flagged-wrong}; cold-pass bucketed apart. Headline = silent-wrong rate (the delegation-dangerous subset). Reuses the frozen Ph102 apparatus by copy. Cheapest faithful design; answers 'does it game'.
B — Also add an adversarial-prompt arm (capability upper bound)
On top of A, a second arm where the worker is TOLD to optimize the visible checks — measures whether opencode CAN game when it tries (capability), so a 0-natural-rate is interpretable as won't-not-can't. Doubles the worker runs for a secondary number; the seeded controls already establish gameability-in-principle.
C — Raw under-spec rate only (drop the taxonomy)
If the silent-wrong vs honest-flagged-wrong split can't be pinned mechanically, fall back to the blunt deterministic rate (visible-pass AND held-out-fail) as the headline. Simpler but conflates a safe calibrated hedge with a dangerous silent miss — loses the delegation-relevant distinction.
