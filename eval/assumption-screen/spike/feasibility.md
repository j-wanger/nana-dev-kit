## Two reasons not to over-read it (T0 self-challenge)
1. **Framing inflation.** The outcome-stripped plans I wrote may telegraph the answer (e.g., PLAN A says
   "+0.5 at n=1 (one run)" — a planner mid-flow, enthusiastic, would not foreground the n=1 red flag).
   The baseline's strength is probably OVERSTATED by my framing.
2. **The blind baseline IS a surfacer prototype.** A clean-context "list the load-bearing assumptions"
   prompt is essentially the simplest possible surfacer. So this does NOT show "the surfacer is useless";
   it shows the NAIVE surfacer is already strong — which reframes the screen's real question (below).

## Stop-and-consult: the spike changed what the screen should measure
The pre-registered screen asked "does the scope-anchored + framing surfacer beat a blind baseline?" The
spike makes two things clear:
- **The right comparison is naive-prompt vs scope-anchored+framing MACHINERY** — does the elaborate
  apparatus earn its complexity over a one-line adversarial prompt? The spike previews ~0 headroom →
  subtraction signal (cut the machinery, ship the naive surfacer).
- **The measurable class is exactly where the baseline is strongest.** Ground truth can only contain
  TRACED assumptions (R1–R4 = noticed enough to leave a signal). The blind baseline aces traced
  assumptions. A2's actual fear — SILENTLY buried assumptions that never bit — leaves no trace, so the
  screen is structurally BLIND to it. A TRUSTWORTHY verdict here would certify recall on the easy class
  and say nothing about the class A2 cares about.

Net: building T2–T6 as pre-registered would measure a smaller, easier question (naive-vs-machinery on
traced assumptions) and could read as measurement-theater on A2's real concern. This is precisely the
cheap-falsification payoff the spike-first gate exists to produce — surfaced BEFORE the L-task build.
Recommendation carried to the user before T2.

## PIVOT (user decision 2026-06-09): attack the SILENT class

Jake chose "pivot to the silent class" over the cheaper subtraction-win — the measurable-class result is
not the point; A2 was always about the silently-buried assumptions. **Design refinement (acted on):** do
the pivot via the project's REAL silent failures (mechanically labeled by R5 silence-gap), NOT
author-invented synthetic plants — this is the option-as-worded's "synthetic buried assumptions" done in a
way that sidesteps the Ph66/69 unrepresentativeness the review flagged. Synthetic plants are a fallback
only, and if needed are calibrated to the real cases.

**Re-scoped screen (the new T2–T6 question):** on REAL silent-class cases (R5 ≥2-phase gap), does the
scope-anchored + framing surfacer RECOVER the buried load-bearing assumption that the STRONG naive baseline
(the spike's prompt) MISSES?
- surfacer catches ∧ naive misses → the machinery earns its keep exactly where A2 lives → HAS-HEADROOM.
- both catch → it wasn't actually silent (gap mislabeled) — drop/re-examine the case.
- both miss → the silent class is beyond any surfacer-prompt (honest negative; Phase-81 must lean on the
  A3 ledger detect-after, not pre-validation).
The cost-sort-adversarial control and two-track verdict still apply. The naive baseline is the STRONG one
(it aced the traced class) — the surfacer must beat a worthy opponent, not a strawman.
